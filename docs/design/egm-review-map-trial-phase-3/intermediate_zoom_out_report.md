# Stage 8 Intermediate Zoom-Out Report (Skeptical Architect)

**Target:** `docs/design/map-trial-phase-3-plan.md`
**Inputs Evaluated:** Stage 5 (`Z5`, `IC5`), Stage 6 (`C6`), Stage 7 (`D7`, `S7`, `St7`), checked against `docs/design/map-trial-build.md`, `docs/adr/0009-map-data-pipeline.md`, and existing Phase 1–2 code (`grid.py`, `blockstage.py`, `pack.py`, `workarea.py`, `cli.py`, `StyleJson.kt`, `TrialFiles.kt`).

## 1. Executive Summary

Stages 5–7 surfaced four real correctness/CI blockers (**IC5-B1 / D7-B1**, **D7-B2**, **Z5-B1**, and **C6-M1 / Z5-N2 / D7-N1**) and several sound simplifications (`grid.py` Web Mercator math, `Dockerfile` layer ordering and thread caps, and numpy pre-filtering before spawning per-block GDAL subprocesses).

Two proposals in Stages 5 and 7 over-engineer the base layer or contradict the approved specification (`map-trial-build.md` lines 306–307, 913, and Goal **G5: Little custom code**):

1. **D7-B1's first option** (extracting the zoom-12 coastline once and letting `tippecanoe` simplify it across `0–2` and `3–5`) contradicts `map-trial-build.md` line 307 (*"Coast: `gdal_contour` at 128 on the same mask, inside the data extent only"*) and causes the low-zoom `coast` line to diverge from the low-zoom resampled `land` polygon boundary. **IC5-B1's single warped array with a 1-px `-1` nodata collar** (also listed as D7-B1's second option) is both simpler and strictly faithful to line 307.
2. **IC5-M1** (in-memory OGR `LineMerge` across block coastlines, `--detect-shared-borders` on `tippecanoe`, or an extra `6..8` sub-band, plus `line-cap`/`line-join` additions to `StyleJson.kt`) violates **G5** and `map-trial-build.md` line 306 (which specifies the spike's exact `tippecanoe` flags and block-grid cuts). It is **rejected**.

- **Rejected:** D7-B1 (Option 1 only), IC5-M1, D7-M1 (replacing `gdal raster polygonize` with `gdal.Polygonize` and custom rectangle synthesis).
